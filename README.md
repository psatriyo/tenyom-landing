# SatuPage marketing site and interview demo

Marketing one-pager, legal drafts and clickable mockups for **SatuPage** (satupage.com): **"Halaman bisnismu di internet, cukup satu link."** A phone-first business page for Indonesian small businesses, led by food and drink businesses with a shop (cafés, restaurants, warung, bakeries), with home food sellers as the secondary segment.

Built from the requirement documents (`2027-project-requirement-documents`, 20 Nov 2026, commit `b58a8c4`, decisions up to **D-78**). Where the previous version of this site (the 19 Nov export) disagrees with them, the requirement documents win. The main changes since that export:

| Decision | What changed on the site |
|---|---|
| D-77 | New tagline and supporting line: "Menu atau katalog, cabang, link dan WhatsApp dalam satu halaman." |
| D-76 | Copy, hero, examples and demo lead with cafés and restaurants. The example page is now **Warung Sari** (restaurant, 2 branches) instead of Kue Bu Rina |
| D-73 | The WhatsApp cart, order message and order log are P2: removed from the landing page, the example page and the dashboard. "Tanya via WhatsApp" stays |
| D-74 | Branch blocks are in the MVP: on the example page, in the pricing and in the FAQ |
| D-75 | Pro sells your own brand (no badge, colours), no limits, 90-day stats and Insights, and promos and "Baru" labels (P1, marked "segera"). No ads on any plan |
| D-71 | New free offer: "Coba dulu: halamanmu kami buatkan" (concierge page). The founding-member deposit offer is switched off |
| D-78 | The dashboard checklist counts "≥3 menu items or 1 branch" |

The site is the founder's prop for the Phase 0 interviews (until 20 Dec 2026): it explains the product in under a minute, lets the interviewee tap through an example restaurant page and dashboard in Free and Pro, and shows how to start before the beta. **No real sign-up, no database, no payments.**

- Static HTML, CSS and JavaScript, generated by a zero-dependency Node script (`scripts/build.mjs`, Node 18+).
- Indonesian-only interface (NFR-13), mobile-first from 360 px (NFR-04), plain `<a href>` to wa.me so links work in Instagram, TikTok and WhatsApp in-app browsers (NFR-03).
- **No cookies, no analytics, no third-party scripts, fonts or images.** The only outside request is the wa.me link a visitor taps. The Pro price chosen with `?harga=` is kept in `sessionStorage` for the open tab only.

| Want to | Do |
| --- | --- |

| Show what Pro adds to the page | `/contoh/warungsari/?paket=pro`, or tap **Pro** in the dark bar at the top: no badge, own colours, promo and "Baru" labels |

| Offer a concierge page (Gate 0, D-71) | "Minta dibuatkan halaman" in the "Mulai sebelum beta" section opens the founder's WhatsApp |
| Start fresh | Close the tab (the price choice lives only in that tab) |

## Configuration: `site.config.mjs`

All brand, domain, price and contact values are in this one file. Edit it and rebuild.

| Key | Default | Status |
| --- | --- | --- |
| `brandName`, `domain` | SatuPage, satupage.com | Decided (Q-04) |
| `appDomain` | app.satupage.com | D-70. Not linked in the demo: "Masuk" opens the "uji coba" sheet |
| `founderWhatsApp` | set | Used by "Hubungi kami", the "uji coba" sheet and both offer buttons. Empty opens WhatsApp's "choose a chat" screen with the message filled in |
| `supportEmail` | empty = `[EMAIL DUKUNGAN]` | Open. Shown in the footer once set |
| `demoMerchantWhatsApp` | empty (falls back to `founderWhatsApp`) | Number the example page sends to ("Tanya via WhatsApp", branch contacts, reservation). Never a stranger's number |
| `pricing.proMonthlyOptions`, `proMonthlyDefault`, `priceParam` | 49000 / 99000, default 99, `?harga=` | Open (Q-03, decided at Gate 1, 29 Mar 2027) |
| `pricing.annualMonthsPaid` | 10 | Annual = 12 months for the price of 10 |
| `limits.*` | 20 items, 10 links, 8 icons, 7 / 90 days | 204, D-32, D-43, D-48 |
| `conciergeOffer.*` | enabled, area "Jabodetabek" | D-71. Free concierge page, live only with the merchant's OK. Turn off once Gate 0 has enough pages (they must be live by 13 Dec 2026) |
| `foundingOffer.*` | **off**, Rp149.000, 3 months, refund by 15 Feb 2027 | P-06, to confirm; no longer a Gate 0 criterion (D-71). Turned off by the founder on 20 Nov; `enabled: true` brings it back |
| `dates.betaOpens` | 2027-02-15 | Shown in the "uji coba" sheet, the offers and the FAQ |
| `siteUrl`, `basePath` | `https://satupage.com`, `/` | Canonical URLs, Open Graph, sitemap |

The "Mulai sebelum beta" section shows when either offer is on.
The example page's data (menu, branches, links, stats, Insights) is in `src/data/warungsari.mjs`.

## Legal drafts

`content/legal/*.md` hold the export's text unchanged. Edit them there; the build turns them into pages.
Rendering rules: the opening `> **DRAF …**` block becomes the banner at the top; any `[TEXT IN BRACKETS]` that is not a link is highlighted as an unfinished placeholder; `##` headings form the table of contents; links such as `/kebijakan-konten` point to the other two pages. Replace the drafts with the advisor-reviewed versions after the 31 Jan 2027 session, and remove the banner only once they are in force.

## Deploy to GitHub Pages

`.github/workflows/pages.yml` builds the site and deploys `dist/` on every push to `main` (or by hand from the Actions tab). In **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**, and keep the custom domain (`CNAME`, `satupage.com`).

## Content rules

- No fake testimonials, merchant counts, ratings or "trusted by" logos. "Warung Sari" is a persona and every demo page says it is an example (D-61).
- Features not live at launch carry "segera" (Insights, promos and labels). Nothing out of scope or parked is promised: no web ordering or cart (P2, D-73), buyer payments, marketplace, native app, English UI.
- Lead with "your business page on the internet" (D-77); the menu or catalog, branches and the WhatsApp button stay central. Not "another Linktree" (R16): no creator features, and "no ads" is a selling point (D-75).
- Prices as integers formatted `Rp99.000` (NFR-14). Friendly "kamu" on marketing pages, formal "Anda" in the legal drafts (NFR-17).
- Tap targets at least 44 px, body text at least 16 px, WCAG AA contrast, alt text on images (NFR-27, NFR-28, NFR-29).
- Founding-member offer: honest framing, no countdown or fake scarcity.

### Template syntax

`{{ value }}` (escaped), `{{{ value }}}` (raw), `{{> partial }}`, `{{#if value}}…{{else}}…{{/if}}`, `{{#unless value}}…{{/unless}}`, `{{#each list}}…{{/each}}` (item fields in scope, plus `this` and `index`). Unknown values stop the build with an error, so typos are caught.
