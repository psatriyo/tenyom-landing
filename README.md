# SatuPage marketing site and interview demo

Marketing one-pager, example page and dashboard, and legal pages for **SatuPage**: **"Halamanmu di internet, cukup satu page."** / "Your place on the internet, all on one page." A phone-first page for Indonesian businesses, creators and individuals: menu or catalog, portfolio, branches, links and an optional WhatsApp button on one page.

**Live at:** https://psatriyo.github.io/tenyom-landing/ (Indonesian) and https://psatriyo.github.io/tenyom-landing/en/ (English).

The landing page copy, section order and audiences follow the product's own landing page in [`psatriyo/satupage`](https://github.com/psatriyo/satupage) (decisions up to **D-103**, 25 Nov 2026). The requirement documents' decision log wins over both. The main changes from the previous version of this site:

WhatsApp is optional; wording is neutral ("pengunjung", "item", "menu atau produk") |
| D-102, D-103 | New **"Untuk siapa"** section with five audiences, and new FAQ questions for PO sellers, photographers and designers, musicians and public figures, and personal pages |

| D-70 | "Masuk" opens `app.satupage.com/login`; every sign-up button opens `app.satupage.com/register`, passing on `utm_*` and `ref` (F-01-FR9). The "uji coba" sheet is gone |
| — | **English version** at `/en/`, with an ID \| EN switch in the header and the demo bar |
| — | Legal pages now carry the product's short holding texts (drafts, not in force) |

Kept from the previous version, as interview tools: the monthly/annual toggle, the "Mulai sebelum beta" section (free concierge page, D-71; founding-member offer, switched off), the interactive example page and dashboard with their Free/Pro switch.

- Static HTML, CSS and JavaScript, generated by a zero-dependency Node script (`scripts/build.mjs`, Node 18+).
- Indonesian by default, English at `/en/`. Mobile-first from 360 px (NFR-04), plain `<a href>` to wa.me so links work in Instagram, TikTok and WhatsApp in-app browsers (NFR-03).
- **No cookies, no storage, no analytics, no third-party scripts, fonts or images.** The only outside requests are the wa.me and app links a visitor taps.

## Using it in an interview

| Want to | Do |
| --- | --- |
| Show the other audiences | Tap **PO**, **Fotografer**, **Musisi** or **Pribadi** above the phone in the hero. They are fictional mock-ups and link nowhere |
| Show what Pro adds to the page | `/contoh/warungsari/?paket=pro`, or tap **Pro** in the dark bar at the top: no badge, own colours, promo and "Baru" labels |
| Show the limits and the upgrade reason | `/contoh/dasbor/`: "Pemakaian paket" shows menu items and links against the Free limits |
| Offer a concierge page (Gate 0, D-71) | "Minta dibuatkan halaman" in the "Mulai sebelum beta" section opens the founder's WhatsApp |
| Track where a sign-up came from | Share the site with `?utm_source=…&utm_medium=…&utm_campaign=…` or `?ref=…`: the sign-up and sign-in links pass them on to the app |
| Show it in English | Tap **EN** at the top right, or open `/en/` |

## Configuration: `site.config.mjs`

Brand, domain, price and contact values are in this one file. Edit it and rebuild.

| Key | Default | Status |
| --- | --- | --- |
| `brandName`, `domain` | SatuPage, satupage.com | Decided (Q-04, D-97). `domain` is the product domain used in example URLs (`satupage.com/warungsari`) |
| `appUrl` | `https://app.satupage.com` | D-70. "Masuk" → `/login`, sign-up buttons → `/register` |
| `siteUrl`, `basePath` | `https://psatriyo.github.io`, `/tenyom-landing/` | Where this site is served: canonical URLs, Open Graph, sitemap. For a custom domain, set `basePath: "/"`, the domain in `siteUrl`, and add a `CNAME` file at the repository root |
| `founderWhatsApp` | set | Used by "Hubungi kami" and both offer buttons. Empty opens WhatsApp's "choose a chat" screen with the message filled in |
| `supportEmail` | empty | Open. Shown in the footer once set |
| `demoMerchantWhatsApp` | empty (falls back to `founderWhatsApp`) | Number the example page sends to ("Tanya via WhatsApp", branch contacts, reservation). Never a stranger's number |
| `pricing.proMonthly` | 69000 | Interim Pro price (D-79), the same as the product |
| `pricing.annualMonthsPaid` | 10 | Annual = 12 months for the price of 10 |
| `limits.*` | 20 items, 10 links, 8 icons, 7 / 90 days, 7 grace days, 6 branch contacts | 204, D-32, D-43, D-48 |
| `conciergeOffer.*` | enabled, area "Jabodetabek" | D-71. Free concierge page, live only with the merchant's OK. Turn off once Gate 0 has enough pages |
| `foundingOffer.*` | **off**, Rp149.000, 3 months, refund by 15 Feb 2027 | P-06, to confirm. `enabled: true` brings it back |
| `dates.betaOpens` | 2027-02-15 | Shown in the "Mulai sebelum beta" section and the FAQ |

The "Mulai sebelum beta" section, and the FAQ question "Kapan bisa mulai?", show when either offer is on.

## Text and languages

All interface text is in **`src/i18n/id.mjs`** (Indonesian, at `/`) and **`src/i18n/en.mjs`** (English, at `/en/`). Templates read it as `{{ t.… }}`. Both files must have the same keys and list lengths: the build stops and names what is missing if they do not. Numbers and prices come from the config, never typed into the text.

Not translated, as in the product: merchant content (menus, branch names, links, the fictional examples in `src/data/examples.mjs`), prefilled WhatsApp messages, and the legal texts.

The example page's data (menu, branches, links, stats, Insights) is in `src/data/warungsari.mjs`.

## Legal pages

`content/legal/*.md` hold the product's legal holding texts (`psatriyo/satupage`, `content/legal/`). Edit them there and copy them over, or edit them here; the build turns them into pages.
Rendering rules: the opening `> **Draf …**` block becomes the banner at the top; any `[TEXT IN BRACKETS]` that is not a link is highlighted as an unfinished placeholder; `##` headings form a table of contents (none is shown when a document has no `##` headings); links such as `/kebijakan-konten` point to the other two pages. Remove the banner only once the final texts are in force.

## Build and run locally

```bash
node scripts/build.mjs
```

The site is built for the base path `/tenyom-landing/`, so serve it from a folder that contains `dist/` under that name:

```bash
mkdir -p /tmp/site && ln -sfn "$PWD/dist" /tmp/site/tenyom-landing && python3 -m http.server 8000 -d /tmp/site
```

Then open http://localhost:8000/tenyom-landing/. The output in `dist/` is ignored by git.

## Deploy to GitHub Pages

`.github/workflows/pages.yml` builds the site and deploys `dist/` on every push to `main` (or by hand from the Actions tab). In **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**. If a custom domain is still set under **Settings → Pages → Custom domain**, remove it: the site now uses the default address `psatriyo.github.io/tenyom-landing/`.

## Content rules

- No fake testimonials, merchant counts, ratings or "trusted by" logos. "Warung Sari" is a persona and the four other examples are labelled "contoh · fiktif"; every demo page says it is an example (D-61).
- Features not live at launch carry "segera" (Insights, promos and labels). Nothing out of scope or parked is promised: no web ordering or cart (P2, D-73), buyer payments, marketplace, native app.
- Lead with "your place on the internet, on one page" (D-103); the menu or catalog, branches and links stay central. More than a list of links (R16), and "no ads" is a selling point (D-75). Fan pages and pages about someone else are not allowed (D-102, D-103).
- Prices as integers: `Rp69.000` in Indonesian, `Rp69,000` in English (NFR-14). Friendly "kamu" in Indonesian.
- Tap targets at least 44 px, body text at least 16 px, WCAG AA contrast, alt text on images (NFR-27, NFR-28, NFR-29).
- Founding-member offer: honest framing, no countdown or fake scarcity.

### Template syntax

`{{ value }}` (escaped), `{{{ value }}}` (raw), `{{> partial }}`, `{{#if value}}…{{else}}…{{/if}}`, `{{#unless value}}…{{/unless}}`, `{{#each list}}…{{/each}}` (item fields in scope, plus `this` and `index`). Unknown values stop the build with an error, so typos are caught.
