# BookBook marketing site and interview demo

Marketing one-pager, legal drafts and clickable mockups for **BookBook** (working name, D-22): a phone-first homepage, catalog and WhatsApp ordering tool for Indonesian UMKM.
Built from the *landing-page and demo export* of 19 Nov 2026 (requirement-documents commit `1ef6476`). Where the previous version of this site disagreed with that export, the export wins.

The site is the founder's prop for the Phase 0 interviews (23 Nov – 20 Dec 2026): it explains the product in under a minute, lets the interviewee tap through an example shop page and the Pro order flow, and shows the founding-member offer. **No real sign-up, no database, no payments.**

- Static HTML, CSS and JavaScript, generated by a zero-dependency Node script (`scripts/build.mjs`, Node 18+).
- Indonesian-only interface (NFR-13), mobile-first from 360 px (NFR-04), plain `<a href>` to wa.me so links work in Instagram, TikTok and WhatsApp in-app browsers (NFR-03).
- **No cookies, no analytics, no third-party scripts, fonts or images.** The only outside request is the wa.me link a visitor taps. The demo keeps its cart and demo orders in `sessionStorage` for the open tab only.

## Pages

| Path | Content |
| --- | --- |
| `/` | Header (Masuk, Coba gratis), hero, masalah, solusi, cara kerja, pesanan (Pro), Insights (segera), harga, anggota pendiri, aman, FAQ, closing CTA, footer |
| `/contoh/kueburina/` | Example shop page "Kue Bu Rina": category tabs, item sheet, "Tanya via WhatsApp", Free/Pro switch. Pro adds the cart, "Pesan via WhatsApp · N item", name and note fields and the formatted order message |

| `/syarat-layanan/`, `/kebijakan-privasi/`, `/kebijakan-konten/` | The three legal **drafts (v0.1, not in force)**, rendered from `content/legal/*.md` with the draft banner, highlighted `[PLACEHOLDERS]` and a table of contents |
| `/404.html` | Not-found page |
| `/terms/`, `/privacy/`, `/pricing/`, `/help/` | Redirects from the previous version of the site |

The demo pages and legal drafts carry `noindex`, so the persona shop and the drafts do not show up in search.
Merchant pages will live at `/[slug]` on the product domain, so add `contoh`, `syarat-layanan`, `kebijakan-privasi` and `kebijakan-konten` to the product's reserved-slug list.

## Using it in an interview

| Want to | Do |
| --- | --- |
| Show Rp49.000 instead of Rp99.000 | Open `/?harga=49` once. Every Pro price on every page follows, including the annual price (Rp490.000) and the dashboard's upgrade buttons. It stays for that browser tab; `/?harga=99` switches back |
| Start the example shop in Pro | `/contoh/kueburina/?paket=pro`, or tap **Pro** in the dark bar at the top |
| Show the order landing in the dashboard | In Pro, add items, tap "Pesan via WhatsApp", send. Then "Lihat di contoh dasbor" |
| Start fresh | Close the tab (cart, demo orders and the price choice live only in that tab) |

## Configuration: `site.config.mjs`

All brand, domain, price and contact values are in this one file. Edit it and rebuild.

| Key | Default | Status |
| --- | --- | --- |
| `brandName`, `domain` | BookBook, bookbook.id | Open (Q-04, due 15 Feb 2027) |
| `appDomain` | app.bookbook.id | D-70. Not linked in the demo: "Masuk" opens the "uji coba" sheet |
| `founderWhatsApp` | empty = `[NOMOR WHATSAPP]` | Open. Used by "Hubungi kami", the "uji coba" sheet and the founding-member button. Empty opens WhatsApp's "choose a chat" screen with the message filled in |
| `supportEmail` | empty = `[EMAIL DUKUNGAN]` | Open. Shown in the footer once set |
| `demoMerchantWhatsApp` | empty (falls back to `founderWhatsApp`) | Number the example shop sends to. Never a stranger's number |
| `pricing.proMonthlyOptions`, `proMonthlyDefault`, `priceParam` | 49000 / 99000, default 99, `?harga=` | Open (Q-03, decided at Gate 1, 29 Mar 2027) |
| `pricing.annualMonthsPaid` | 10 | Annual = 12 months for the price of 10 |
| `limits.*` | 20 items, 10 links, 8 icons, 7 / 90 days | 204, D-32, D-43, D-48 |
| `foundingOffer.*` | enabled, Rp149.000, 3 months, refund by 15 Feb 2027 | P-06, to confirm. `enabled: false` removes the section and its links |
| `dates.betaOpens` | 2027-02-15 | Shown in the "uji coba" sheet and the FAQ |
| `siteUrl`, `basePath` | `https://tenyom.com`, `/` | Canonical URLs, Open Graph, sitemap |

The example shop's data (products, prices, links, mock orders, stats, Insights) is in `src/data/kueburina.mjs`.

## Legal drafts

`content/legal/*.md` hold the export's text unchanged. Edit them there; the build turns them into pages.
Rendering rules: the opening `> **DRAF …**` block becomes the banner at the top; any `[TEXT IN BRACKETS]` that is not a link is highlighted as an unfinished placeholder; `##` headings form the table of contents; links such as `/kebijakan-konten` point to the other two pages. Replace the drafts with the advisor-reviewed versions after the 31 Jan 2027 session, and remove the banner only once they are in force.

## Build and run locally

```bash

```

python3 -m http.server 8000 -d dist

## Deploy to GitHub Pages

`.github/workflows/pages.yml` builds the site and deploys `dist/` on every push to `main` (or by hand from the Actions tab). In **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**, and keep the custom domain (`CNAME`, `tenyom.com`).

## Content rules (from the export)

- No fake testimonials, merchant counts, ratings or "trusted by" logos. "Kue Bu Rina" is a persona and every demo page says it is an example (D-61).
- Features not live at launch carry "segera" (Insights). Nothing out of scope for 2027 is promised (buyer payments, marketplace, native app, English UI).
- Lead with the homepage; the catalog and WhatsApp orders stay central. Not "another Linktree" (D-46, R16).
- Prices as integers formatted `Rp99.000` (NFR-14). Friendly "kamu" on marketing pages, formal "Anda" in the legal drafts (NFR-17).
- Tap targets at least 44 px, body text at least 16 px, WCAG AA contrast, alt text on images (NFR-27, NFR-28, NFR-29).
- Founding-member offer: honest framing, no countdown or fake scarcity.

### Template syntax

`{{ value }}` (escaped), `{{{ value }}}` (raw), `{{> partial }}`, `{{#if value}}…{{else}}…{{/if}}`, `{{#unless value}}…{{/unless}}`, `{{#each list}}…{{/each}}` (item fields in scope, plus `this` and `index`). Unknown values stop the build with an error, so typos are caught.
