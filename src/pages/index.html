Satu link untuk semua

Taruh satu link di bio Instagram, TikTok, status WhatsApp, banner, dan kemasan. Pembeli langsung lihat semuanya.

Pesan langsung ke WhatsApp

Lihat kunjungan, klik WhatsApp, dan klik per link. Tanpa cookie, tanpa melacak pengunjung.

Paket Pro

Chat jadi daftar pesanan yang rapi Pro

Pembeli pilih produk, isi jumlah, lalu tekan “Pesan via WhatsApp”. Pesanan langsung tercatat di dasbor kamu, dan WhatsApp terbuka dengan pesan yang sudah rapi.

  • Nomor pesanan otomatis, gampang dicocokkan dengan chat (“Pesanan #12”).
  • Status: Baru → Dikonfirmasi → Selesai.
  • Pembayaran tetap langsung ke kamu (QRIS atau transfer milikmu). Kami tidak menyentuh uang pembeli dan tidak ambil komisi.
  • Kami tidak meminta nomor HP pembeli.

Kepercayaan

Aman dan menghargai privasi

  • Halaman toko tanpa cookie dan tanpa pelacak pihak ketiga.
  • Statistik berupa hitungan anonim. Nomor HP pembeli tidak disimpan.
  • Setiap halaman ditinjau sebelum tayang selama masa beta. Tidak ada tempat untuk judi online dan penipuan; siapa pun bisa melaporkan halaman.
  • Data disimpan di server Singapura.

FAQ

Pertanyaan yang sering ditanyakan

Apakah benar-benar gratis?

Ya. Paket Gratis bisa dipakai selamanya: sampai {{ limits.freeItems }} produk, {{ limits.freeLinks }} link, dan tombol “Tanya via WhatsApp”. Bayar hanya kalau butuh fitur Pro.

Apa bedanya dengan Linktree atau link bio lain?

{{ brandName }} dibuat untuk penjual barang: ada katalog dengan harga, tombol tanya per produk, dan pesanan via WhatsApp. Link ke marketplace dan media sosial tetap bisa dipasang.

Apa bedanya dengan katalog WhatsApp Business?

Kamu dapat halaman bermerek yang bisa dibuka siapa saja dari bio, QR, atau kemasan, lengkap dengan link ke semua tempat jualanmu, statistik, dan (di Pro) pesanan yang tercatat rapi.

Apakah {{ brandName }} ambil komisi?

Tidak. Pembeli membayar langsung ke kamu. Kami tidak menyentuh uang pembeli.

Bagaimana cara bayar Pro?

Pakai QRIS atau transfer bank, bulanan atau tahunan. Tidak ada potong otomatis.

Kalau saya berhenti bayar Pro?

Fitur Pro tetap jalan 7 hari, lalu akun kembali ke Gratis. Data tidak dihapus; produk dan link di atas batas Gratis hanya disembunyikan.

Perlu aplikasi?

Tidak. Semua lewat browser di HP, dan dasbornya bisa dipasang di layar utama seperti aplikasi.

Saya cuma jualan di Shopee. Bisa?

Bisa. Kamu bisa membuat halaman berisi link saja, lalu tambah katalog kapan pun.
